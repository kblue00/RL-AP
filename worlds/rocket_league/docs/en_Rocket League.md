# Rocket League

This Archipelago integration uses Rocket League's local Stats API to recognize match wins, goals, shots on goal, demos, saves, and—when **Non1v1 Mode** is enabled—assists and MVPs. It does not hook into the game process. On Windows, the client can map XInput controller buttons, triggers, D-pad directions, and cardinal stick directions to keyboard or mouse outputs.

Collect the configured Win Tickets from randomized locations. Once the required ticket count is reached, win the configured number of additional matches to complete the goal.

The **Ability Unlocks** option controls whether ability items are included in the pool. It is enabled by default. When disabled, the five ability items are omitted and their item slots become filler; controller actions are available without waiting for unlocks. When enabled, **Boost**, **Ball Cam**, **Jump/Flip**, and **Brake** are progression items, while **Air Roll** is useful. Controller inputs assigned to those actions are suppressed during active matches until their items arrive. Jump Trap can inject Jump briefly while Jump/Flip is locked. Once per saved slot and seed, on the first `RoundStarted` event while Ball Cam is locked, the client sends one Ball Cam toggle, assuming the game starts with it enabled. The Stats API does not expose Ball Cam's current state, so this cannot detect or guarantee the actual on/off state. In the **Bindings** tab, assign each controller input a keyboard or mouse output, whether or not it has a Rocket League action assigned. Selecting an action also sets that action's key for traps; **Unassigned** inputs send their mapped output directly. Brake corresponds to handbrake / powerslide; the Spin Trap uses that configured key. HidHide must hide the physical controller from Rocket League while allowing the Archipelago client to read it. Stick directions are digital and do not preserve analog magnitude. Generate a new world for the option to take effect.

The **Per-Match Checks** options set the number of goal checks (3–7), shot-on-goal checks (3–10), demo checks (1–6), and save checks (1–6) available in each match. When **Non1v1 Mode** is enabled, the Assist checks option adds 1–6 assist milestones per match and **MVPs** sets 1–20 MVP awards to earn across separate matches. The client identifies MVP from the winning team by comparing score, goals, assists, saves, then shots. If all those values are tied, the API provides no explicit MVP marker, so the client leaves that MVP check unearned. Save milestones use the game's `Saves` stat, which includes epic saves when the game counts them as saves.

Quick-chat themed items are filler and have no in-game effect. Input traps run only while the Stats API reports an active match and Rocket League is the foreground application. Traps received outside a match wait until the next active match. Scoreboard holds its key for five seconds; Boost holds for six seconds; Spin holds handbrake, forward, and left for five seconds; Ball Cam and Jump tap their keys at random intervals for five seconds. Ball Cam Trap has no effect if received before the Ball Cam unlock, and cannot guarantee the final camera state because the API does not report it. DeathLink sends when you are demolished, with a random Rocket League themed cause. Receiving a DeathLink blocks mapped forward and reverse controller inputs for 10 seconds during an active match. Inputs are released if the match ends or the client shuts down. Configure action keys in the Bindings tab; slash commands remain available as an optional alternative. Bindings persist locally between client launches.

The **DeathLink** option controls whether demolitions send DeathLinks and whether received DeathLinks apply their effect. **Trap Percentage** controls the share of filler slots filled with traps (default 15%). Individual trap weights range from 0 to 10 and control how often each trap is selected relative to the others.
